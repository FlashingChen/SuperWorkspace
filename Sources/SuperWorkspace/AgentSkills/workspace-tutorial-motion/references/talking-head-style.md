# 全屏口播美学基因、3D 运镜与视觉规范（`aRoll`）

> 锁定底层美学基因与空间纪律，具体每一帧的表现形式回到第一性原理自由创作，拒绝“万物皆套圆角卡片”。

## 1. 真实 A-Roll 与 3D 暗色舞台的呼吸配比（约 30% 实拍 : 70% 动态舞台）

**严禁把整条视频 100% 用暗色舞台盖死！** 人物永不消失，在以下形态间自然切换：

- **0.0–1.8s（纯真实 A-Roll 开场）**：原生实拍直接开口建立眼神交流，不铺黑幕。
- **1.8–4.5s（实拍 + 透明 `behindPerson` 厚重压字）**：使用透明 `overlays` + `matte: "behindPerson"` 在真实画面人物肩后做逐字弹簧弹出的厚重主标题（英文 `Arial Black / Impact`、中文 `PingFang SC 900`，加描边与立体投影）。
  - **景别适配**：若原片是近景大头照，绝不把窄字硬塞在额头正后方导致遮挡看不清；应抬高至发际线上沿或左右分置在头部两侧（例如左 2 字 + 右 2 字），确保 100% 可读。
- **每 12–18 秒及片尾 3–4 秒回到实拍喘息**：让宿主 `sw-motion.mjs` 自动将人物丝滑放大回 `1.0` 全屏真实 A-Roll，配轻量液态玻璃侧边微胶囊（`SpokenMicroPill`）或透明 `behindPerson` 金句，讲完再丝滑缩小滑入下一幕。
- **人物前景登台比例**：`personForeground` 紧凑讲解推荐 `personScale: 0.40–0.45`（约占画面高度 38%–44%），稳重清晰不抢戏。

## 2. 3D 世界相机（`WorldCamera`）与三层景深纪律

不只是画布里的元素在动，拍摄画布的虚拟相机本身也在动：

1. **必须做有明显感知的 3D 推拉与倾角**：
   - 每个全屏 `shots` 包在 `<StageFrame>` + `<WorldCamera keys={...}>` 内（自动按 1920 逻辑宽等比缩放，兼容 1080p / 3K / 4K）。
   - 单幕至少包含 **2 次明显运镜变化**：建立全景（`scale: 0.94`）→ 3D 推进聚焦（`scale: 1.18–1.28`, `rotateY: ±6~10°`, `rotateX: ±2~4°`）→ 摇镜到下一个焦点 → 拉回全局揭示，并保留自带云台微呼吸（`floatAmount: 0.65`）。
   - **安全区检查**：推进到最大倍率时，核心元素绝不撞顶部 HUD、不撞人物前景、不在画边意外裁切。
2. **三层视差层次**：
   - **远景层（`0.42×` 视差）**：干净深炭黑摄影棚径向光效与细腻点阵（严禁放巨型汉字水印或私人频道水印）；
   - **中景世界层（`1.0×` 3D 相机）**：全部视觉叙事元素、真实录屏窗口（`MacWindowStage`）、数据矩阵与连线；
   - **前景人物层 + 锁定 HUD 层（`0×` 不随相机）**：宿主合成的人物前景（自动两段式无重影平滑缩放/滑行转场）与固定在 `<StageFrame header={...}>` 的液态玻璃 `CornerBadge` / `TopStepperBar` / 右下角 `MonoFootnote`。
3. **弹簧物理与同幕对象变形**：
   - 统一使用 `springIn` / `springMorph` 做弹性入场与同幕重排（例如卡片先居中展示，讲到对比时平滑飞散腾出舞台），拒绝死板线性硬切。

## 3. 克制语义色盘与液态玻璃（Liquid Glass）规范

- **画布深炭黑**：`#0A0C12` / `#0D0E12`（舞台底用径向微聚光 `radial-gradient(ellipse at 50% 35%, #161922 0%, #0D0F14 55%, #07080B 100%)`）
- **电光青**（正向、主力方案、选中高亮）：`#22D3EE` / `#38BDF8`
- **琥珀金**（重磅结论、核心价值、话题微标）：`#FACC15` / `#F59E0B`
- **珊瑚红**（痛点吐槽、避坑 `≠`、报错告急）：`#EF4444` / `#F87171`
- **翡翠绿 / 淡紫**（通过状态 / 并列参照区分）：`#34D399` / `#A78BFA`
- **液态玻璃材质**：`CornerBadge`、`TopStepperBar`、`SpokenMicroPill`、`LiquidMeter` 已内置半透明折射底 + 顶部微高光描边，直接复用，勿给整片底图或录屏主体加模糊遮罩。
- **视觉禁令**：
  - **绝对禁止 Emoji**（一律使用官方 SVG Logo 或 `VectorIcon`）；
  - **绝对禁止编造假数据**（无真实查证数据时用 `LiquidMeter` 的 `valueText` 展示定性状态，有查证数据时用 `MonoFootnote` 标明来源）；
  - **禁止连续两幕重复同一版式**，交替使用「实拍人后压字 / 居中元素矩阵+飞散重排 / 双栏对称对比+人物正中支点（`personAnchor: "bottomCenter"`）/ 浅灰顶栏 `MacWindowStage` 真实录屏推近 / 液态玻璃指标标尺」。
