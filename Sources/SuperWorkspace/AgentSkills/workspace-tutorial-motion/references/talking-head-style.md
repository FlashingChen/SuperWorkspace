# 全屏口播美学基因、实体材质与构图规范（`aRoll`）

> 锁定杂志纪录片级的实体美学与克制秩序，具体每一帧回到第一性原理做视觉叙事，彻底告别“赛博发光毛玻璃 + 万物皆套圆角胶囊”的廉价 AI 模板感。

## 1. 真实 A-Roll 与全屏舞台的黄金配比（60%–70% 实拍 : 30%–40% 全屏舞台）

**主线永远是“真人在讲”，不要动不动把整个房间抹黑！**

- **纯实拍开场（0.0–1.5s）**：原生实拍直接开口建立眼神交流，不铺黑幕。
- **实拍 + 轻量侧边证据层（主力形态）**：用透明 `overlays` 直接叠在真实房间画面两侧，不遮挡人物：
  - 人物左侧放哑光实体主题卡（`EditorialRankCard`，如红榜/黑榜/核心结论，宽度 `300–340px`）；
  - 人物右侧放杂志风极简细线数据条（`DataRuleList`，带真实出处与日期）或纸质账单/引语卡；
  - 需要强冲击大字时，用 `matte: "behindPerson"` 在人物肩后或头部左右两侧分列厚重主标题（英文 `Arial Black / Impact`、中文 `PingFang SC 900`）。近景大头照绝不把窄字硬塞额头正后方，应左右分列在头部两侧（例如左 2 字 + 右 2 字）确保 100% 可读。
- **高密度全屏暗色舞台（仅在真正需要空间叙事时切入）**：
  - 适用场景：**多品牌纯白扑克牌阵摊开/收拢（`BrandDeckCard`）、二维定位象限图（`QuadrantPlot`）、大厂生态连线版图、物理/流程视觉隐喻动画、真实录屏放大（`MacWindowStage`）**。
  - 人物使用 `matte: "personForeground"` 缩小至右下角或左下角（`personScale: 0.34–0.42`），把 85%–90% 画面让给信息本身；讲完关键论点后平滑回到实拍。

## 2. 实体材质与克制色盘（反廉价铁律）

- **纯白实体牌（`#FFFFFF`）**：专门承托下载下来的**真实官方彩色/单色 SVG Logo**（`BrandDeckCard`），在深炭黑背景上形成极高对比度与印刷品般的利落质感。
- **哑光实体主题卡**：
  - 猩红（红榜 / 强推 / 高亮结论）：`#C81E1E` → `#991B1B` 哑光渐变 + `1.5px` 低对比白边；
  - 炭黑（黑榜 / 短板 / 冷静剖析）：`#171B24` → `#0E1016` + `1px` `rgba(255,255,255,0.16)` 细边；
  - 暖白纸面（真实账单 / 原文引语 / 对话批注）：`#FAF9F5` / `#F4F4F0` + 荧光黄 `#FDE047` 高亮条。
- **极简细线数据条（`DataRuleList`）**：`1px` 水平分割线 + `3px` 细进度条 + 等宽 `tabular-nums` 右对齐数字 + 底部 `11px` 大写等宽溯源（`letter-spacing: 0.08em`, 55% 透明度）。
- **克制语义点缀色**：
  - 理性数据蓝：`#38BDF8` / `#0284C7`
  - 结论琥珀金：`#FBBF24`
  - 警示猩红：`#DC2626` / `#EF4444`
  - 正向翡翠绿：`#10B981`
- **明确视觉禁令**：
  - **绝对禁止手绘任何品牌/公司/模型 Logo**（必须真实下载官方 SVG 到 `public/assets/logos/`，找不到则用纯文字标）；
  - **绝对禁止 Emoji**；
  - **绝对禁止编造假数据与假出处**；
  - **禁止大面积使用发光霓虹毛玻璃大胶囊**（`SpokenMicroPill` 仅可作为极少量短词标签点缀，不得作为整片主体视觉）。

## 3. 3D 世界相机（`WorldCamera`）与逐拍生长节奏

1. **逐拍生长，绝不一上来全坨甩在脸上**：口播提到哪一个品牌、哪一组数据、哪一条短板，那一帧才用 `springIn` / `springMorph` 弹出对应元素（例如先出 2 张牌 → 讲到更多时顺次补齐 → 再收拢成扇形一排）。
2. **全屏舞台必须带克制的 3D 镜头调度**：`<StageFrame>` + `<WorldCamera keys={...}>`，单幕至少 2 次有目的的推拉或摇镜（建立全景 `scale: 0.94` → 推近核心节点/数据区 `scale: 1.16–1.24`, `rotateY: ±5~8°` → 拉回揭示全局），并保留轻微云台呼吸（`floatAmount: 0.55`），推进时核心文字与 Logo 严禁被裁切或撞字幕区（底部 14%）。
3. **禁止连续两幕重复同一版式**：交替使用「实拍 + 侧边红/黑卡与细线数据条 / 纯白品牌牌阵 / 二维定位象限图 / 纸面原文荧光笔批注 / 真实录屏窗口推近 / 物理隐喻动画」。
