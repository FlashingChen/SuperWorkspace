# 界面规范

## 布局

原生 macOS SwiftUI 工作台，支持浅色、深色与跟随系统。

- 默认窗口 1240 × 800，最小内容尺寸 1100 × 700。
- 项目导航固定于窗口左侧，展开宽 220、收起宽 56，贯穿内容区高度；不使用垂直居中的浮动卡片。顶部为应用标识与收起入口，下方依次为新建项目、项目库和可滚动的最近项目列表，设置置于底部。保存展开状态；项目行不逐项添加分隔线，选中项使用低对比度底色。
- 工作区顶部导航高 80，与侧栏应用标识同高。录制与拼装步骤在工作区水平居中，以带编号的圆角选项和连接箭头呈现。左侧为当前项目名称；右侧为拼装阶段的成片导出。
- 当前步骤使用 `accent` 细描边与同色 10% 填充；项目选中状态以字重和中性底色标识。图标使用 SF Symbols。
- 应用标识使用 `WorkspaceBrand` 的深蓝叠放画布与橙色播放符号；侧栏和应用包共享矢量源，Dock 在窗口初始化时显式设置图标。
- 标题与正文左对齐。录制空状态共用不对称双栏，左侧预览舞台，右侧操作。
- 工作区内容宽度上限 `Metrics.content`，水平边距 `space11`，栏间距 `space9`，操作列宽 200–224。
- 内容高度小于 640 时，顶部和底部边距缩为 24，主分组间距缩为 28；其余情况下顶部边距 52，分组间距 40。
- 视频容器使用 16:9 比例、`radiusL` 圆角与 `mediaGround` 底，原始画面由原生播放器等比显示。
- 素材页内容宽度上限 1200、内边距 32，缩略图网格列宽 300–420。每张卡片由固定 16:9 缩略图和一行元数据组成，处理状态用带辅助功能名称的图标表示，处理详情按需展开。取消、重试和时间线编辑放在更多菜单。拼装页上方为原生视频预览与右侧字幕文字编辑，下方为可缩放的双轨时间线，可拖动分隔条调整区域比例。
- 时间线采用固定轨道标签、横向滚动标尺与按实际时长排列的片段；视频显示真实缩略帧，字幕使用暖色块，播放头与选中素材使用焦点色。播放控制统一位于时间线工具条，预览不重复显示原生控制条。

## 色彩

颜色由 `Theme.swift` 的 `Palette` 提供，两套主题各自完整、互不借用。token 的权威定义在设计系统的 `tokens.json`。

| token | 用途 | 浅色 | 深色 |
| --- | --- | --- | --- |
| `bgBase` | 工作区主画布 | `#fbf8f1` | `#101823` |
| `bgSidebar` | 项目导航 | `#f4efe3` | `#0c121b` |
| `bgDeep` | 凹陷表面：时间线、播放器外框 | `#e9e2d0` | `#080d15` |
| `surface1` | 悬停底色与弱填充 | `#f1ebdd` | `#1a2333` |
| `surface2` | 分隔线、列表底纹 | `#e3dbc8` | `#283244` |
| `surface3` | 强中性填充：滑块轨道、拖放目标 | `#c9c0a9` | `#3d4a5d` |
| `borderStrong` | 需要 3:1 的控件外框 | `#877d64` | `#6e7c90` |
| `textPrimary` | 标题与正文 | `#1a2940` | `#f3eee3` |
| `textSecondary` | 次级正文与说明 | `#46505f` | `#b7c0cd` |
| `textMuted` | 分组标题、快捷键提示 | `#5a6474` | `#96a2b2` |
| `accent` | 焦点、选中、播放头、滑块 | `#3a6488` | `#8fb0cb` |
| `brand` | 录制信号与品牌 | `#e6572e` | `#f0713f` |
| `ai` | AI 动效与字幕校正状态 | `#6b4c93` | `#c7aeea` |
| `success` | 完成状态 | `#2a702e` | `#7fc98a` |
| `warning` | 字幕块与待处理警告 | `#8f5405` | `#e3a757` |
| `danger` | 错误与删除确认 | `#b53326` | `#f08a86` |
| `mediaGround` | 视频画面底 | `#191a1c` | `#191a1c` |

- 主按钮使用 `textPrimary` 填充、`bgBase` 文字；选中块使用 `accent` 的 10% 填充；状态同时提供文字或图标，不单靠颜色。
- 品牌橙只做信号（录制中、品牌标识），不用于 24px 以下文字，也不做小字底。
- 视频画面区固定 `mediaGround`，两套主题同值，避免界面色温影响画面判断。
- 文字只有三级：`textPrimary` / `textSecondary` / `textMuted`。需要更弱就换字号或加留白，不要新造一档灰。
- 对比度基线：正文在 `bgBase`、`bgSidebar`、`bgDeep`、`surface1` 上不低于 4.5:1；控件外框与焦点环不低于 3:1。改色前先验证。

## 字体

只用系统 SF 字，时间码与时长用等宽。字号一律走 `Font.studio(_:)`，不要直接写 `.system(size:)`。

| 样式 | 规格 | 用途 |
| --- | --- | --- |
| `display` | 36 / 40 / 500，字距 −0.8 | 页面主标题，一页一个 |
| `title` | 24 / 30 / 500，字距 −0.4 | sheet 与面板标题 |
| `heading` | 22 / 28 / 600 | 内容区分组标题 |
| `subhead` | 18 / 24 / 500 | 操作列与检查器小节 |
| `bodyLarge` | 15 / 22 / 400 | 输入框、项目名、要读的正文 |
| `bodyLargeMedium` | 15 / 22 / 500 | 项目卡片标题 |
| `body` | 13 / 20 / 400 | 正文默认 |
| `bodyMedium` | 13 / 20 / 500 | 按钮、步骤名、字段标签 |
| `small` | 12 / 17 / 400 | 元数据与提示 |
| `smallStrong` | 12 / 17 / 600 | 工具条标题、卡片标题 |
| `caption` | 11 / 15 / 500 | 分组标题、列表标签 |
| `micro` | 10 / 14 / 500 | 快捷键与角标 |
| `timecode` | 11 / 16 / 400 等宽 | 时间码与时长 |

数字会跳动的地方（时长、百分比、时间码、步骤序号）加 `monospacedDigit()`；`micro` 只放非必要信息。

## 间距、圆角与尺寸

- 间距按 4pt 网格，`Metrics.space0_5`(2) 到 `Metrics.space13`(52)，常用 8 / 12 / 16 / 24 / 36。
- 圆角四档：`radiusXS` 4、`radiusS` 6、`radiusM` 8（最常用）、`radiusL` 12；胶囊取自身高度的一半。
- 控件高度：`controlCompact` 28、`control` 38、`choice` 36、`row` 34、`bar` 42、`toggleRow` 46、`header` 80。
- 固定宽度：`sidebar` 220、`sidebarRail` 56、`content` 1000、`contentWide` 1200、`inspector` 260。
- 内容尺寸（片段高度、轨道高度、画面比例、窗口尺寸）不当作 token，直接写字面值。

- `StudioButtonStyle` 提供 primary、secondary、quiet、destructive 四种状态；常规按钮高度不低于 38，compact 工具栏按钮高度不低于 28，圆角 8，包含悬停、按下和禁用反馈。
- Secondary 使用单层细边框，Quiet 只在悬停和按下时显示背景。普通页面不添加装饰阴影。
- 成片导出面板使用画幅比例选择块；当前画幅和跟随素材置于上行，横屏、竖屏、方形置于下行。`StudioSelectionStyle` 以焦点色描边和勾选标识选中状态；`StudioToggleStyle` 提供整行可点的字幕开关及原生辅助功能语义。取消与导出共用 `StudioButtonStyle`，面板适配浅色与深色。
- 新建项目使用聚焦名称输入的原生 sheet，支持回车创建、Escape 取消及 Command-N 快捷键。
- 图标按钮提供辅助功能名称。装饰图标不参与辅助功能朗读。
- 任务错误提示可选择，素材重试与后台处理状态保持可见。

## 媒体与状态

- 项目库支持浏览、新建和进入项目，侧栏可随时返回所有项目。
- 录制入口使用同进程录制组件，保留内置粗剪和素材导出流程。
- 录制素材按项目归属保存，AI 动效与字幕继续在后台处理，不改变当前项目选择。
- 素材页保留处理状态、错误提示和重试入口，点击完成素材可打开预览。
- 拼装页支持按顺序预览、素材前后移动、按时间跳转、通过轨道边缘拖动裁剪素材和调整字幕时长，支持字幕整体移动及在播放头处分割素材；原片与动效可切换，编辑支持撤销与重做。
- 原始素材就绪后允许预览与无字幕导出。开启字幕导出时须完成字幕；未完成的动效使用原片，并明确标示。导出状态按项目隔离，显示实际进度与取消入口。
- 页面更新复用播放器，离开预览页面时暂停播放并释放时间观察器。

- 素材删除收纳于卡片的更多菜单和时间线片段的右键菜单，不作为常驻文字按钮；破坏性菜单项置于末尾并与排序操作分隔，确认后执行。

- 预览与导出使用同一字幕合成实现。编辑阶段、播放位置、选中项、缩放与区域比例按项目恢复。最近导出常驻提供播放与 Finder 入口。

- 选中片段的两端显示紧凑边缘握柄，鼠标悬停使用水平调整光标。拖动时轨道即时反馈，松手后统一提交并保留一步撤销；不在检查器展示起止秒数输入。导出画幅和字幕选项集中于成片导出面板。

## 控件接入规则

所有应用自绘控件必须使用共享组件，不得回退到未经设计的系统默认控件外观。共享组件保留原生交互与键盘、辅助功能语义。

| 控件 | 实现 |
| --- | --- |
| 主操作、取消、辅助操作、删除 | `StudioButtonStyle`，根据层级选择 kind 和 size |
| 缩略图、项目导航 | `StudioContentButtonStyle`，标签负责布局，样式负责悬停、按下和禁用反馈 |
| 画幅和离散选项 | `StudioSelectionStyle` / `StudioChoice`，焦点色描边标识选择 |
| 布尔开关 | `StudioToggleStyle`，整行可点，保留原生开关辅助功能表示 |
| 单行与多行输入 | `StudioTextFieldStyle`，统一内边距、表面和焦点描边 |
| 工具菜单入口 | `StudioMenuStyle`，紧凑命中区与悬停反馈，弹出菜单由 macOS 管理 |
| 高级配置展开 | `StudioDisclosureStyle`，共享按钮与展开状态朗读 |
| 素材预览播放 | `StudioPlayer`，自绘播放按钮、时间码与播放位置滑块 |
| 时间线缩放与预览进度 | `StudioSlider`，使用主题绘制的轨道和滑块，保留 NSSlider 的跟踪、键盘与辅助功能 |
| 错误与删除确认 | `StudioMessageSheet`，统一标题、正文和操作栏；删除不绑定回车快捷键 |

设置窗口使用共享选项切换外观、动效和字幕分类，内容可滚动；不使用默认 TabView、分段选择器或 Form 控件外观。录制完成面板通过宿主样式闭包接入同一按钮和开关。已有录制器专用定制控件沿用其设计系统。

系统菜单内容、文件选择器和权限提示保留 macOS 管理的呈现。底层 `.plain`、`.borderlessButton` 只允许出现在共享组件实现内。新增控件应先补充共享实现，再接入页面；检查浅深主题、禁用状态、键盘焦点与长文本，不增加无必要的辅助说明。
