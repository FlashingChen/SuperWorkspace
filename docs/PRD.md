# 产品需求与功能规范

SuperWorkspace 是以项目为单位组织录制、素材处理、拼装和导出的原生 macOS 视频工作台。

本文件是能力、流程、状态与规则的权威说明，不描述界面布局、控件和视觉。安装与构建见 [README](../README.md) 和 [QUICKSTART.md](QUICKSTART.md)。

## 1. 定位与边界

- 运行于 macOS 14 及以上；发布包为 Apple Silicon。技术栈为 Swift 6、SwiftUI、AppKit、AVFoundation、Core Image、Vision。
- 录制器以同进程组件运行，不提供独立应用入口、独立应用代理或独立更新实现。
- 本地优先：语音识别、画面预分析、拼装与合成在本机完成；AI 能力全部可选。
- 产物：一个 MP4；字幕可嵌入画面，也可关闭，并可另存 SRT。
- 非目标：多视频轨与自由叠加、调色与混音、多语言字幕轨、直播与云端协作、Windows 与 Linux、账号体系与云同步、应用自动更新。

## 2. 术语与数据模型

### 2.1 项目

项目是编辑、任务与导出的边界。一个项目包含多段素材、一份素材库和一组导出选项。

| 字段 | 含义 |
| --- | --- |
| `name` | 项目名称；留空时使用「未命名项目」 |
| `materials` | 有序素材列表，顺序即成片顺序 |
| `referenceMedia` | 素材库，图片或视频 |
| `includeSubtitles` | 导出时是否把字幕合成进画面，默认开启 |
| `exportSRT` | 导出时是否另存 SRT |
| `exportWithAIEditing` | 导出时是否执行 AI 剪辑 |
| `canvasWidth` / `canvasHeight` | 成片画布；为空表示跟随素材 |
| `lastExportName` / `lastExportSRTName` | 最近一次导出文件名，用于再次播放与定位 |

### 2.2 素材与时间线片段

素材由录制组件导出后加入项目。一次录制产生一个素材；在时间线上分割后产生共享同一原始媒体的多个片段。

| 字段 | 含义 |
| --- | --- |
| `id` | 片段标识 |
| `mediaID` | 原始媒体标识；分割产生的片段共享该标识 |
| `duration` | 原始媒体时长 |
| `exportState` | 录制组件导出状态：`running` / `complete` / `failed` |
| `motionState` | AI 动效状态 |
| `transcriptState` | 字幕状态 |
| `subtitles` | 字幕条目，时间为原始媒体时间 |
| `inserts` | 录制期 AI 剪辑方案中的补充画面 |
| `wantsMotion` / `wantsAIEditing` | 该素材导出时选择的 AI 能力 |
| `editingPrompt` | 剪辑提示词，供动效与 AI 剪辑使用 |
| `useOriginal` | 有已完成动效时是否改用原片 |
| `trimStart` / `trimEnd` | 入点与出点，空表示整段 |

派生规则：

- `sourceReady`：时长有效且 `exportState == complete`。
- 入点 `inPoint` 取 `trimStart` 并夹在 `[0, duration]`；出点 `outPoint` 取 `trimEnd` 且不小于入点。
- 时间线时长 `timelineDuration = outPoint - inPoint`。
- 可见字幕：与 `[inPoint, outPoint]` 求交后平移，完全落在范围外或时长为零的条目被丢弃。
- 片段就绪 `isReady`：`sourceReady` 且时间线时长大于零。

同一 `mediaID` 的片段共享一次字幕识别、一次动效任务和同一份字幕数据；裁剪范围、排序位置、原片选择各自独立。处理状态变化会同步到同组片段。

### 2.3 素材库素材

素材库素材是用于补充说明的图片或视频，导入时复制进项目目录。字段包括名称、类型、说明与视频时长。说明用于让模型理解「这条素材适合讲什么」。

### 2.4 字幕条目

`{ start, end, text }`，时间以所属原始媒体为基准。项目级字幕由各片段可见字幕按顺序偏移拼接而成，用于预览、导出与 SRT。

拼装阶段可以逐条编辑字幕：修改文字、调整起止时间、整体平移、在定位点分割、与下一条合并、在空位新增或删除。增删与合并只改变字幕轨，不改变画面与声音；同一原始媒体的多个片段共享同一份字幕数据。

### 2.5 任务状态

```text
idle → queued → running → complete
                    ↘ failed →（重试）queued / running
```

- 素材导出、AI 动效与字幕各自持久化状态；AI 剪辑以进行中阶段、已保存方案和失败提示表示。
- 用户取消、执行失败、超时或应用退出都会落到 `failed` 或保留可用结果，不会伪装成完成。

## 3. 能力总览

| 能力域 | 能力 | 触发 | 产物 |
| --- | --- | --- | --- |
| 项目 | 新建、选择、恢复编辑阶段 | 用户操作 | `project.json` |
| 录制 | 屏幕、窗口、麦克风、系统声音、可选摄像头；内置粗剪 | 录制新素材 | 原始媒体 |
| 素材 | 加入项目、排序、裁剪、分割、删除、原片/动效切换 | 录制完成或时间线操作 | 素材列表 |
| 素材库 | 导入、说明、自动描述、移除 | 用户操作或导入后自动 | 素材库副本与说明 |
| 字幕 | 本地识别、自动拆条、AI 校正、拼装阶段整轨重建、逐条增删/合并/分割、文字与时间调整 | 素材就绪后自动、手动复核 | `transcript.json`、`subtitle-review.json` 等 |
| AI 动效 | 画面预分析、派发 Remotion 任务、结果校验、重试 | 录制时选择或手动重试 | `motion.mp4`、分析记录 |
| AI 剪辑 | 依据字幕、提示词、素材库规划裁剪与补充画面 | 录制时选择或导出时开启 | 片段裁剪与补充画面计划 |
| 拼装 | 双轨时间线、预览、字幕复核与手动编辑、撤销重做 | 时间线操作 | 项目状态与编辑会话 |
| 导出 | 画布、嵌入字幕、SRT、进度与取消 | 导出成片 | MP4、SRT |

## 4. 端到端流程

### F1 建立项目

1. 用户新建项目并命名；名称为空时使用「未命名项目」。
2. 应用创建项目目录并写入 `project.json`，项目立即成为当前项目。
3. 编辑阶段、定位点、缩放、预览比例与选中项按项目保存；重新进入或重启后恢复。

失败处理：写入失败时保留原项目列表并给出错误，不产生半成品项目。

### F2 录制并生成素材

1. 用户在当前项目发起录制；若录制会话已打开，则回到该会话，不重复创建。
2. 录制组件完成权限引导与来源选择，按屏幕、窗口、麦克风、系统声音、摄像头采集。
3. 用户在内置粗剪中裁剪，确认导出。可选择「添加 AI 动效」「AI 剪辑」，任一开启时填写剪辑提示词。
4. 记录所选 AI 能力后导出视频到当前项目的素材目录；导出期间素材处于 `running`。
5. 导出成功后读取实际时长，标记 `complete`，并按需锁定画布、派发字幕、动效与 AI 剪辑。
6. 导出失败时标记 `failed` 并保留错误信息，素材仍可见，可重新录制或移除。

约束：

- 选择 AI 动效或 AI 剪辑但未配置可用的 AI 连接时，导出在开始前被拒绝，不创建素材。
- 录制任务绑定发起时的项目，之后切换项目不影响其归属。
- 麦克风默认启用；启用状态下麦克风未就绪时阻止开录。

### F3 后台处理

素材导出完成后独立派发：

1. **字幕**：提取声音 → whisper.cpp 识别 → 保存原始结果 → 可选 AI 校正 → 按显示宽度拆条 → 写入 `transcript.json`。无音轨的素材直接得到空字幕列表。
2. **AI 动效**（素材选择了动效）：加入全局串行队列 → 画面预分析 → 派发执行器 → 校验结果 → 回填 `motion.mp4`。
3. **AI 剪辑**（素材选择了 AI 剪辑且未同时选择动效）：等待该素材字幕完成 → 依据字幕、提示词与素材库规划 → 校验并保存补充画面。

处理期间素材可用于预览：动效未完成、失败或选择原片时使用原始画面；字幕只使用当前已生成的内容。任务可取消；失败可重试。

### F4 素材库维护

1. 用户导入图片或视频；每个文件复制进项目素材库目录，并登记名称、类型、视频时长。
2. 导入时校验：图片需可解码；视频需可播放、含视频轨、起点为 0、时长不少于一帧。
3. 可手写说明；启用图像模型后可生成或重新生成一句中文描述，也可在导入时自动补齐缺失说明。
4. 移除素材时删除项目内副本；导出进行中不允许移除。

单个文件失败不影响其余文件，失败名称汇总提示。

### F5 拼装与校对

1. 素材按列表顺序组成时间线；项目画布在素材全部就绪后锁定。
2. 预览使用与导出一致的合成结果：画布、裁剪、排序、补充画面与嵌入字幕。
3. 用户调整顺序、裁剪入出点、在指定时间点分割片段、修改字幕文字与时间。
4. 所有编辑按项目撤销与重做；每次拖动只产生一个撤销步骤。
5. 编辑阶段、定位点、缩放、区域比例与选中项持续保存，供下次恢复。

失败处理：素材未全部就绪时预览给出明确原因；字幕处理中的字幕不可编辑。

### F6 导出成片

1. 用户选择画布、是否嵌入样式字幕、是否另存 SRT、是否执行 AI 剪辑。
2. 应用校验导出前置条件；不满足时拒绝导出并说明原因。
3. 若开启 AI 剪辑且项目尚无已保存方案，先规划一次覆盖整个项目的方案，并把方案中的裁剪范围应用到本次导出。
4. 单素材、未裁剪、无补充画面且不嵌入字幕时直接复制画面与声音；否则按顺序合成并重编码。
5. 导出显示实际进度，可取消；完成后保存最近产物信息，并写出 SRT（如需）。
6. 导出失败或取消时删除未完成的输出文件。

### F7 中断与恢复

应用启动时检查上次运行遗留状态：

| 遗留状态 | 结果 |
| --- | --- |
| 素材导出 `running` | 标记 `failed`，提示重新导出 |
| 动效 `queued` / `running` | 标记 `failed`，可重试 |
| 字幕 `running` | 无字幕则标记 `failed`；已有字幕则标记 `complete` 并提示处理中断 |
| 字幕布局版本过期 | 按当前分段规则重新拆条，语音内容不变时优先使用已保存的原始识别结果 |

## 5. 功能详述

### 5.1 项目管理

- 项目按更新时间倒序展示；新建后立即进入该项目。
- 进入项目时恢复其编辑阶段；若素材已导出但尚未识别字幕，自动补跑字幕。
- 项目列表来自影片目录中的项目文件夹；无法解析的项目文件被跳过，不阻塞其他项目。

### 5.2 录制与素材导出

- 屏幕与窗口录制、麦克风、系统声音、摄像头由录制组件提供；录制来源选择不暴露设备录制入口。
- 内置粗剪后导出为 MP4；导出结果即素材画面。
- 每次录制可单独选择「添加 AI 动效」「AI 剪辑」，剪辑提示词同时服务两者。
- 同时选择动效与 AI 剪辑时，只执行动效：素材库画面应在动效镜头内渲染，避免同一素材出现两次。
- 素材时长以导出结果为准；无法读取时长视为导出失败。

### 5.3 本地字幕识别

- 声音通过 FFmpeg 转为 16 kHz 单声道 WAV。
- whisper.cpp 使用配置的 GGML 模型与语言，限长 36 字符、优先在词边界切分，应用再按显示宽度拆条。
- SRT 解析为时间轴条目；原始识别结果保存为 `transcript-raw.json`，校正后的结果保存为 `transcript.json`。
- 无音轨时不调用 whisper，直接保存空列表并标记完成。

自动拆条规则：

- 显示宽度中，ASCII 字符计 1，其他字符计 2；单条上限 36（约 18 个中文字）。
- 优先在标点后拆分，其次词边界；不拆断连续的拉丁词。
- 细分时间按各段显示宽度在原时间段内按比例分配，不改变总时长。

### 5.4 AI 字幕校正与复核

- 默认开启；仅在配置了可用 AI 连接时生效，配置缺失时自动退化为纯本地识别。
- 按每批 30 条处理；每批附带前后相邻语句与最多 5 帧画面的本地 OCR 文字，用于消除同音词、术语与英文拼写歧义。
- 允许调用随包搜索工具核实活动名、赛事名、产品名等专有名词；检索结果只用于确认写法。
- 模型只返回按编号对应的文字，不返回时间码；应用保留原时间段。
- 结果校验：条目一一对应、不得为空、长度与编辑距离受限、拉丁字母不得被翻译掉、比例受限、简繁与原文一致；未通过则本批保留本地结果。
- 任一批失败不影响其他批，最终给出可重试提示；整段未被修改时提示无需修改。
- 原始识别结果始终单独保存，校正可重复执行。

**拼装阶段复核**

- 复核在拼装面板手动触发；AI 复核使用与校正相同的连接，但有独立开关。没有可用 AI 连接时只做本地检查与明显碎句合并。
- AI 复核按「录制」（同一 `mediaID` 的全部片段共享一份字幕）重建整条字幕轨：每次请求包含该录制的全部字幕、素材时长、各片段入出点与最多 3 帧本地画面 OCR 文字（每帧最多 900 字）。
- 模型输出完整的 `captions` 列表，可以修正识别错误、重新断句、合并碎句、拆分长句、调整每条的开始与结束时间；不得翻译、改写、总结或增删实际说出的内容（明显的重复识别可以删除）。每条字幕的长短与断句由模型根据语义、语速和可读性决定，应用不设固定字数上限。
- 结果校验：时间位于 `0–素材时长`、按时间排序、互不重叠（重叠部分裁到前一条之后）、单条 0.05–15 秒、条数不超过原条数的 3 倍加 5；首末条相对原轨的偏移与总显示时长受跨度约束，防止把整轨压到开头或丢掉结尾；文本长度比例 0.8–1.2、整体编辑距离受限、拉丁字母与中日韩字符各至少保留 60%。阈值见 6.2。
- 任一校验失败视为该录制重建失败，保留原字幕，不阻塞其它录制；每个录制最多尝试 2 次。
- 通过的整条轨道替换该录制所有同源片段的字幕；复核期间被手动修改过的录制跳过，不覆盖用户编辑。整次重建记录为一步撤销。
- 本地检查（无 AI）覆盖：相邻字幕时间重叠、单条过短或过长、语速过快、单行过长、相邻内容重复、首尾多余空白、片段入出点截断句子、单独成条的英文功能词。明显碎句由本地规则直接合并，其余作为需要留意项。
- 复核结果与重建统计保存在项目的 `subtitle-review.json`；重新识别或重新校正字幕、或复核规则版本变化时清除旧结果。
- 复核只重建字幕轨，不改变画面、声音、片段裁剪、字幕位置与样式。

### 5.5 AI 动效

**画面预分析（本机）**

- 每 0.5 秒采样一帧，做人脸检测与亮度差分，得到画面分区、切点、关键帧、是否存在全屏人物与混合画面。
- 分区：`aRoll`（全屏人物）、`screenDemo`（录屏/演示）、`mixed`（人物与演示共存，附加无人物的一侧）。
- 切点：相邻采样平均亮度差超过阈值的时刻，0.6 秒内不重复；短于 1 秒的分区并入相邻分区。
- 关键帧：每个分区中点，最多 8 张。

**可动范围策略**

| 规则 | 取值 |
| --- | --- |
| 允许全屏图解 | 仅 `aRoll`，最多 1 段 |
| 允许局部叠加 | `aRoll` 与 `mixed` |
| 必须保留原画面 | `screenDemo` |
| 入画时长上限 | 素材时长的 15%，夹在 6–12 秒 |
| 交付目标 | 9 分钟 |

**任务派发**

- 全局串行：同一时刻只执行一个动效任务，其余排队。
- 任务说明包含输入输出路径、剪辑提示词、字幕摘录（最多 2000 字）、画面分区与切点、可动区间、预算与素材库说明；模型支持图片时把最多 4 张素材库画面作为附件，要求渲染进镜头并自行设计背景与入退场。
- 模型支持图片时随任务附上分区关键帧（最多 6 张）；否则按输入视频重新抽取关键帧。
- 执行器为内置 Pi（OpenAI 兼容接口，启用工具）或 Claude CLI；内置 Pi 使用随包 `workspace-tutorial-motion` 技能与 Remotion。
- 首次任务按固定清单安装 Remotion 依赖与浏览器到应用支持目录缓存，之后复用。
- 预算：时长预算按素材时长增长（8 分钟起，每 30 秒加 1 分钟，上限 25 分钟），工具调用次数同向增长（100 起，每 2 秒加 1 次，上限 300）；达到 70% 时提醒收尾，达到 100% 时中止并报「超出预算」。
- 进度按阶段与工具调用回传：预分析、准备、模型轮次、工具执行、重试、收尾；密钥不会进入执行器子进程的环境变量。

**结果校验与回填**

- 结果需可播放、含视频轨、时长与原片相差不超过 0.1 秒；原片有声音时结果必须保留音轨。
- 校验失败不使用结果并报告原因；传输类瞬时故障自动重试一次（间隔 3 秒），预算中止、取消与校验失败不自动重试。
- 成功后写入 `motion.mp4`；素材可在原片与动效之间切换，动效失败或未完成时使用原片。
- 执行记录保留任务说明、预分析 JSON、执行器回复与耗时信息，便于复核。

### 5.6 素材库

- 支持的导入对象为图片与视频，可一次导入多个文件；视频必须可播放、含视频轨、时间轴从 0 开始且不少于一帧。
- 文件复制进项目目录，源文件之后移动或删除不影响项目。
- 说明可为空；空说明时 AI 剪辑会依据素材名称、画面内容与画面文字推断用途。
- 描述生成要求图像模型：取一张画面截图，请求一句中文描述（最长 60 字）；空回复、拒答、超过 200 字或请求失败时保留原说明并标记可重试，过长但可用的描述截断到 60 字。
- 移除素材时删除项目内副本；导出期间禁止移除。

### 5.7 AI 剪辑

AI 剪辑用素材库中的图片或视频替换片段局部画面，做补充说明。

**规划输入**

- 片段：标识、当前入出点、范围内的字幕、剪辑提示词。
- 素材库：名称、类型、说明；模型支持图片时附画面截图并编号；同时提供画面 OCR 文字。
- 未命名说明的素材由文件名与画面文字补足提示。

**规划输出与校验**

```json
{
  "clips": [{ "id": "片段标识", "start": 0, "end": 5 }],
  "inserts": [{ "clipID": "片段标识", "assetID": "素材标识", "start": 1, "end": 3, "assetStart": 0 }]
}
```

- `clips` 必须覆盖每个输入片段各一次，输出顺序即剪辑顺序；省略边界表示保留原边界。
- 裁剪范围必须落在原片段范围内，且不短于一帧。
- 补充画面不得重叠、不得超出片段范围、不得短于一帧，必须指向存在的素材库素材。
- 图片的 `assetStart` 固定为 0；视频的起始时间与插入时长之和不得超出素材时长。
- 规划调用最多两次：首次可带图片；失败或返回空内容时以纯文本重试一次。
- 任一校验失败视为规划失败；录制期的失败保留原片并给出可重试提示，不影响素材使用；导出期的失败终止本次导出并报错。

**生效方式**

- 录制期且未同时选择动效时，方案保存在素材上；裁剪变化或素材库素材被移除后，超出范围的补充画面在预览与导出时被丢弃，不阻塞导出。
- 导出期方案覆盖整个项目：先按方案的裁剪范围改写片段，再在导出中使用补充画面；该方案不写回项目的裁剪设置，也不进入预览。
- 补充画面只替换画面，保留原片段声音与字幕；图片放在深色舞台与媒体窗中，视频在舞台背景上按原比例适配，均不得直接贴在纯黑底上。

### 5.8 拼装与时间线编辑

- 时间线按实际时长排列片段，顺序即导出顺序。
- 支持定位到任意时间、逐帧移动、播放/暂停、缩放（0.5–64 倍）与适应全片。
- 顺序调整：把片段拖到目标片段之前或之后，也可通过前后移动操作；字幕与导出顺序同步。
- 裁剪：选中片段后调整入点或出点，范围限制在 `[0, duration]` 且不短于一帧；相邻边界与定位点参与吸附，按住 Option 临时取消吸附。
- 分割：在定位点处分割片段，两侧各不短于一帧；右半段共享原始媒体与后台任务，编辑范围独立。
- 字幕编辑：修改文字；调整单条起止时间，必须位于素材范围内、不短于一帧、且不与相邻条目重叠；拖动整条字幕整体平移。
- 新增字幕：在定位点插入空白字幕，默认 2 秒，夹在素材范围与相邻字幕之间；定位点已有字幕或空位不足一帧时提示先调整。
- 删除字幕：删除只移除字幕轨内容，画面、声音与其它字幕的位置不变。
- 合并字幕：与下一条合并为一条并延续两者时间范围；中文直接拼接，拉丁词之间补一个空格。
- 分割字幕：在定位点把一条字幕分成两条，文字按时间比例切分；拉丁词不拆开，无法切分时保持整条。
- 同一原始媒体的多个片段共享字幕数据，增删、合并与分割同步到这些片段；离开可见范围的条目不参与预览与导出。
- 选中字幕后，分割操作作用于字幕；未选中字幕时分割仍作用于素材。
- 复核问题在字幕块与字幕列表中按严重程度着色；点击复核条目定位到对应字幕与时间点。
- 原片切换：有已完成动效的素材可在原片与动效之间切换，切换参与撤销。
- 预览重建后保持定位点与播放状态；离开预览时暂停并释放播放观察者。

### 5.9 撤销与重做

- 撤销栈按项目独立，容量 100 步。
- 可撤销：字幕文字、字幕时间、字幕新增/删除/合并/分割、AI 整轨重建（整步）、裁剪、分割、排序、原片切换、画布、是否嵌入字幕、删除与恢复素材。
- 每次拖动在松手时提交为一步；撤销后仍可重做。
- 字幕被后台识别或校正替换后，该项目此前的编辑历史被清空，避免旧索引作用于新字幕数据。

### 5.10 成片导出

- 画布：当前画布、跟随素材（按最早录制的素材重新计算）、1920×1080、1080×1920、1080×1080；宽高限制在 2–7680，合成时向下取偶。
- 素材顺序决定画面顺序；画布独立于顺序，排序不改变画布。
- 每个片段按入出点截取，等比适配画布居中显示，留白区域为黑底。
- 补充图片绘制在深色舞台与媒体窗中，带缓慢推近与首尾淡入淡出；补充视频在舞台背景上等比适配。字幕最后叠加在画面之上。
- 嵌入字幕使用与预览相同的字幕渲染：居中白字、半透明深色圆角底，字号随画布高度缩放，过宽或过高时自动缩小与换行。
- 重编码时帧率固定 30 fps；常规导出使用 AVFoundation 合成与最高质量预设。
- 快速路径：单素材、无裁剪、无补充画面、不嵌入字幕且画布未设置或与画面一致时，直接复制文件，避免重编码。
- SRT 使用裁剪、排序、导出期 AI 剪辑调整与校对后的时间轴。
- 导出进度按实际编码进度显示，可取消；取消会删除未完成文件，SRT 写出失败时删除本次视频。
- 导出时选择画布、字幕与 AI 剪辑选项会写回项目，作为下次导出的默认值。
- 最近一次导出可从应用再次播放或在 Finder 中定位；同时输出的 SRT 也可单独定位。
- 导出前置条件：至少一段素材；全部素材就绪；若嵌入字幕或另存 SRT，则全部素材字幕已完成。

### 5.11 设置

| 分类 | 选项 |
| --- | --- |
| 外观 | 跟随系统、浅色、深色；减少动态效果 |
| AI 连接 | 内置 Pi：基础地址、模型、密钥、模型是否支持图片、是否自动生成素材描述、连接测试、保存与移除密钥；Claude CLI：执行文件、追加参数 |
| 字幕 | FFmpeg / whisper.cpp / 模型状态；安装字幕工具；选择 GGML 模型；识别语言；AI 校正开关；模型路径与语言代码；识别测试 |

- AI 基础地址只接受 HTTPS；回环地址允许 HTTP。地址自动补齐到 `/chat/completions`；非回环地址必须提供密钥。
- 密钥按服务地址存入 macOS 钥匙串，保存后不再回显。
- 字幕识别测试用 1 秒静音音频跑通 FFmpeg 与 whisper.cpp，用于验证模型可用。

### 5.12 任务与状态管理

- 字幕、AI 剪辑按素材独立执行；AI 动效全局串行。
- 任务阶段文本用于说明当前动作（提取声音、识别字幕、校正字幕、预分析画面、模型轮次、工具调用、收尾等）。
- 取消：动效取消后标记失败并切回原片；字幕取消后保留已生成条目，没有条目时标记失败。
- 重试：动效与字幕可分别重试；AI 剪辑规划失败可单独重试，不重新录制。
- 失败原因在素材上保留可读文本，便于复制与排查。

### 5.13 素材删除

- 删除素材会从项目移除该片段及其字幕，并在没有同源片段时取消相关任务；原始文件保留在磁盘。
- 素材导出中或项目导出中禁止删除。
- 删除参与撤销；恢复时按同源片段同步处理状态，无法恢复的任务标记为可重试失败。

### 5.14 会话恢复

- 保存当前项目、每个项目的编辑阶段、定位点、时间线缩放、预览区域比例与选中项。
- 保存操作按需合并写入，应用退出时再强制写入一次。
- 恢复时忽略已不存在的项目。

## 6. 规则与校验

### 6.1 时间与几何

| 规则 | 取值 |
| --- | --- |
| 最小片段时长 | 1/30 秒 |
| 时间线帧率 | 30 fps |
| 画布宽高 | 2–7680；合成时向下取偶 |
| 裁剪范围 | `[0, 原始时长]`，出点不早于入点 |
| 字幕时间 | 位于素材范围内，不短于一帧，与相邻条目不重叠 |
| 动效结果时长差 | ≤ 0.1 秒 |

### 6.2 字幕

| 规则 | 取值 |
| --- | --- |
| 单条显示宽度 | ≤ 36（ASCII 1，其他 2） |
| 识别切片 | whisper 限长 36，优先词边界；应用再按显示宽度拆分 |
| AI 校正批量 | 30 条/批 |
| 画面 OCR 采样 | 每批最多 5 帧，单帧最多 2000 字 |
| 校正重试 | 每批最多 2 次 |
| 编辑距离上限 | `max(6, 原长度/2)` |
| 长度比例 | 0.6–1.6 |
| 拉丁字母保留 | 至少保留原文的一半 |
| 重建调用 | 每个录制 1 次/轮，最多尝试 2 次 |
| 重建输入 | 全部字幕、素材时长、片段入出点、最多 3 帧 OCR，单帧最多 900 字 |
| 重建时间范围 | `0–素材时长`；单条 0.05–15 秒 |
| 重建条数 | ≤ `max(10, 原条数 × 3 + 5)` |
| 重建文本比例 | 0.8–1.2 |
| 重建文本编辑距离 | ≤ `max(12, 15%)` |
| 重建语言保留 | 拉丁字母、中日韩字符各 ≥ 原文的 60% |
| 重建重叠处理 | 后一条起点裁到前一条结束 + 0.001 秒，过短则丢弃 |
| 重建首末偏移 | ≤ `min(10, max(3, 原跨度 × 0.1))` 秒 |
| 重建显示时长 | 原总显示时长的 0.6–1.4 |
| 复核过短 | 时长 < 0.45 秒且显示宽度 ≥ 6 |
| 复核过长 | 时长 > 8 秒 |
| 复核语速 | > 22 显示单位/秒 |
| 复核单行长度 | > 40 显示单位 |
| 手写字幕最短 | 一帧；新增默认 2 秒 |

### 6.3 动效预算与结果

| 规则 | 取值 |
| --- | --- |
| 预分析采样间隔 | 0.5 秒 |
| 最短分区 | 1 秒 |
| 切点阈值 | 平均亮度差 0.28 |
| 人脸占比判定 | 全屏人物 ≥ 10% 且居中；混合 ≥ 1.5% |
| 关键帧上限 | 8 张 |
| 附件关键帧 | 6 张 |
| 素材库附件 | 4 张 |
| 全屏图解 | 最多 1 段 |
| 入画上限 | `min(12, max(6, 时长 × 0.15))` 秒 |
| 时长预算 | `min(25, 8 + ceil(时长/30))` 分钟 |
| 工具预算 | `min(300, 100 + ceil(时长/2))` 次 |
| 收尾提醒 | 预算的 70% |
| 自动重试 | 瞬时故障 1 次，间隔 3 秒 |

### 6.4 AI 剪辑方案

| 规则 | 取值 |
| --- | --- |
| 规划尝试 | 最多 2 次（第二次不带图片） |
| 补充画面时长 | 一帧至片段时长 |
| 画面重叠 | 不允许 |
| 图片起始时间 | 固定 0 |
| 视频起始时间 | ≥ 0，且插入时长不超出剩余时长 |
| 失效方案 | 超范围或素材缺失的插入被丢弃，不阻塞导出 |

### 6.5 导出前置条件

- 至少一段素材；全部素材 `isReady`。
- 嵌入字幕或另存 SRT 时，全部素材字幕已完成。
- 选择 AI 剪辑时需有可用的 AI 连接。
- 导出中禁止删除素材或移除素材库素材。

## 7. 数据流与隐私

### 7.1 本机处理

- 录制、粗剪、声音提取、语音识别、画面预分析、字幕分段、拼装、字幕渲染与视频合成全部在本机完成。
- 不包含账号、遥测或使用数据上报；除已配置的 AI 服务、依赖下载与字幕校正的联网查证外，不发起网络请求。

### 7.2 外发数据

| 功能 | 外发内容 | 目标 |
| --- | --- | --- |
| 字幕 AI 校正 | 字幕、相邻句、本地画面 OCR 文字、待核实的检索词 | 已配置的模型服务；启用查证时经随包搜索扩展访问检索服务 |
| 字幕 AI 复核 | 该录制的整条字幕轨、素材时长、片段入出点、本地画面 OCR 文字 | 已配置的模型服务 |
| 素材描述 | 一张素材画面截图与素材名 | 已配置的图像模型 |
| AI 剪辑 | 片段字幕、剪辑提示词、素材名称与说明、素材库画面及其中文字 | 已配置的模型服务 |
| AI 动效 | 源帧、画面分析、字幕摘录、素材库画面、任务说明 | 已配置的模型服务 |
| 环境准备 | 固定版本依赖与浏览器下载请求 | 软件源 |

关闭 AI 字幕后，字幕仅使用本地识别与分段。模型输出按第 5.4、5.5、5.7 节的校验规则处理，未通过校验的结果不写入项目数据。

### 7.3 文件布局

项目根目录位于当前账户的影片目录，按项目标识分目录：

```text
<项目>/
  project.json                 项目、素材、字幕与导出选项
  library/<素材标识>.<扩展名>   素材库副本
  materials/<媒体标识>/
    source.mp4                 素材画面
    transcript.json            校正并分段后的字幕
    subtitle-review.json       最近一次字幕复核报告
    transcript-raw.json        原始识别结果
    transcript.srt             whisper 原始 SRT
    audio-16k.wav              提取的 16 kHz 单声道音频
    motion.mp4                 动效结果
    motion-pending.mp4         动效临时输出
    motion-brief.txt           动效任务说明
    motion-analysis.json       画面预分析结果
    motion-timing.json         动效耗时与结果记录
    agent-response.txt         执行器回复
  export-<标识>.mp4            成片
  export-<标识>.srt            可选 SRT
```

工作台状态（当前项目与各项目的编辑会话）保存在项目根目录的 `workspace-state.json`。测试可用环境变量 `SUPERWORKSPACE_TEST_ROOT` 覆盖项目根目录。

### 7.4 兼容与迁移

- 旧版单源项目在读取时转换为一段素材，原文件不移动。
- 字幕布局版本升级时重新分段；若已保存的原始识别结果与当前字幕语音内容一致，则以其为分段来源。

## 9. 验收

**自动化**

- `swift test` 覆盖：时间线与字幕几何、裁剪与分割、字幕增删/合并/分割、整轨重建校验与回填、撤销、删除、任务中断恢复、字幕分段与校正校验、素材描述清洗、动效预分析策略、AI 剪辑方案校验、混排画面与字幕合成、SRT 解析与导出、画布与依赖配置。
- `python3 scripts/audit-public.py` 检查待发布文件中的本机路径、凭据、身份信息与未登记的外部地址。

**无界面端到端验收**

`SuperWorkspace --accept <输入视频> [目标秒数]` 会构造不少于目标时长的素材，走完动效、字幕与导出，校验：

- 动效结果与输入时长相差不超过 2 秒；
- 字幕元数据非空且每条时间有效；
- 导出成片与输入时长相差不超过 2 秒。

`SuperWorkspace --accept-export` 复用最近项目的素材，只重跑导出。验收需要可用的内置 Pi 连接，可通过环境变量覆盖 AI 服务地址与模型。

**人工检查**

- 预览与导出画面、字幕样式、排序与裁剪一致。
- AI 动效需人工确认画面语义；自动校验只能证明时长与音轨，不能证明视觉正确。
- 素材库补充画面位置正确、无拉伸、未被误用到不相关段落。

## 10. 已知限制

- 单一视频轨，补充画面是唯一的画面叠加能力。
- 重编码导出固定 30 fps；导出不提供码率、色彩空间与音频参数选项。
- 动效必须保持原片时长与时间关系，不能改变速度或删减内容。
- 录制期同时选择动效与 AI 剪辑时只执行动效，素材库画面由动效镜头渲染。
- 导出期 AI 剪辑方案不写回项目裁剪设置，也不进入预览。
- 字幕语言提供中文、英文与自动检测，也可在高级配置填写其他 whisper 语言代码；AI 校正与复核保持原文简繁，不做转换。
- 字幕复核会整轨重建文字、断句与时间，但不能保证与语音逐句对齐，也不会调整字幕位置或样式；校验只能保证内容没有大幅增删或翻译。
- 首轮动效需要联网准备 Remotion；离线时动效不可用，其他功能不受影响。
- 视觉类 AI 能力依赖图像模型；Claude CLI 路径不具备图片输入。
